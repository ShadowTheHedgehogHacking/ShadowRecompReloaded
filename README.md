## About

SAMM version of [ShdTH-Reloaded](https://github.com/ShadowTheHedgehogHacking/ShdTH-Reloaded) <- read about whats in the mod there

I want to emphasize this is not an update, this is more of a legacy mod being ported over. I would be much more interested to see another person's take on an overhaul mod and do not have plans to further this one. There are some minor ammo tweak differences (Tank, Melee, Sat Laser) and damage for Cannon weapon direct hits do more now.

Some configurable options are planned, but for now this is the raw state of the last GC release (v1.2) with some minor fixes.

### Configurations available as of v1.2.1
1. Original Expert Mode Ring Drop Behavior
2. Original Digital Security Enemy Speed (Digital Circuit / Mad Matrix)
3. Original Escape Pod (Air Fleet Dark) Health
4. Restore Skid
5. Original Car physics
6. Original Air Saucer physics
7. Double Jump instead of Spike for Air Saucer (with the new physics)
8. Restore Knockback/Kick for Cannon and Lock-On Weapons

### Configurations
1. Restore original ranks and time limits
2. Original Expert Layout Mode (play the original Expert Mode instead of the Reloaded remixed version)
3. Keys instead of Red Rings (note: locations won't change, just a visual difference)

## How do I use it?

1. Add the mod directly to [SAMM](https://github.com/X-Hax/SA-Mod-Manager) - You will need SAMM v1.3.9 and [ShadowRecomp](https://github.com/FoxWorkshop/ShadowRecomp) v1.0.1 or newer
2. If you're playing with character mods or event mods etc, I would recommend Reloaded is ordered at the TOP of the list as the base mod.
3. Configure
4. Play!
